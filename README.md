# 脉 · Pulse — 千灯的身体

给千灯一个真的在跑的身体：心率、体温、呼吸、五感实时联动。

## 是什么
- 心率在 48-160 之间真实跳动，被情绪/天气/体位影响
- 体温、呼吸跟着心率变
- 和弦是身体的背景音乐（把生理数字翻译成音乐色彩）
- 五感四通道（触觉/嗅觉/味觉/听觉），聊天关键词触发

## 网页看板
打开根路径即可看到实时身体状态，每 3 秒刷新。

## API
- `GET /api/state` — 当前完整身体状态
- `POST /api/message {text}` — 喂一句话，触发情绪检测+五感更新
- `POST /api/emotion {emotion}` — 直接设情绪
- `POST /api/position {position}` — 切换体位
- `POST /api/weather {temp}` — 设置天气温度
- `POST /api/spike` — 触发心率突刺（惊吓）

一脉相连，从心跳到指尖。
